#コンパス ガチャ記録 v5.0 変更ファイル

GitHub Pages上の次の2ファイルを差し替えてください。
- index.html
- sw.js

manifest.webmanifest、icon-192.png、icon-512.png は今あるものをそのまま残してください。

iPhoneで sw.js 単体を保存できない場合:
1. このZIPをダウンロードして展開する
2. 中の sw.js を使う
または sw.txt をGitHubへアップロード後、ファイル名を sw.js に変更してください。

レート予想の追加内容:
- シーズン名・終了日時・自分の現在pt・安全マージン
- 好きな日時で観測を保存
- 複数スクショを1回の観測として選択
- スクショの撮影日時を画像メタデータから取得（取得できない場合はファイル日時→現在日時の順で代替）
- スクショから順位とptをOCR
- 読み取り後に手動修正・追加・削除
- 500位/5000位を上下の順位から補間
- 片側しかない場合は外挿し、信頼度を下げて表示
- 観測履歴の編集・削除
- 重複スクショ、同一観測のチェック
- 前回からの増加pt、経過時間、1時間あたりの伸び
- ボーダー推移グラフ
- 最終予想、予想範囲、安全目標、自分との差
- JSONバックアップにレート観測とシーズン設定も追加

注意:
OCRは初回にTesseract.jsを読み込むためネット接続が必要です。
OCR結果は誤認識の可能性があるため、保存前に必ず順位とptを確認してください。
